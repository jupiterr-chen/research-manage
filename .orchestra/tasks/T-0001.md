## 目标(一句话说清"做完长什么样")

管理台已能对接 reports-fetcher 财报原文获取服务(代码与测试已在分支上,见「背景」);
本卡补齐**部署配置**与**接入文档**,使运维只改环境变量就能在「本地 mock」与「NAS 生产服务」之间切换,
且文档能让一个没看过对话的人独立完成启动、测试和切换。

先读(按序):`AGENTS.md` → `CLAUDE.md`(12 条红线)→ `docs/AGENT-PLAYBOOK.md` §2 **S10** 小节 →
`integration-kit/README.md` §1/§7 与 `integration-kit/AGENT_INSTRUCTIONS.md` §四(生产切换要点)。

已实现(**只读参考,本卡不改这些代码**):

## 实现提示

- 三个 compose/env 文件里的变量名必须与 `app/config.py` 中 `Settings.load()` 读取的名字逐字一致,先 `grep -n "REPORTS_API_" app/config.py` 核对。
- 生产 compose 目前 `ports` 绑定 `192.168.1.150:8090:8090`、`user: "1000:994"`,保持原样。
- `host.docker.internal:host-gateway` 在 Linux Docker 28 与 Docker Desktop 都可用;文档里说明这一点。
- 文档语言:简体中文;命令块用 ```bash;不要贴任何真实密钥;不要写"已在生产验证"之类你没做过的话。

## 已知坑

- 本机 shell 环境变量 `HTTP_PROXY=192.168.1.150:1081` 会劫持对 `127.0.0.1:18765` 的 curl;命令前加 `--noproxy '*'` 或 `unset HTTP_PROXY HTTPS_PROXY`。
- Git Bash 里 Python 打印中文可能乱码,不影响功能;需要看清输出时用 `pwsh`。
- mock 状态在内存里,容器重启即清空;测试之间用不同 Idempotency-Key。
