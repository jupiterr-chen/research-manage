# T-12 代理下载文件名:转发 filename* 并生成可读回退名

- ID: T-0003
- 创建: 2026-09-22
- 分支: `fix/T-12-download-filename`(已从 develop 切出并处于当前工作区;不要建分支、不要 commit)

## 目标

浏览器经管理台代理 `GET /api/v1/archive/reports/{id}/file` 下载财报时,拿到的文件名可读:
优先使用上游 `Content-Disposition` 的 `filename*=UTF-8''…`(含中文),并按 RFC 6266 同时给出 ASCII 回退;
上游没给或名字不可读(如以 `unknown__` 开头)时,用本系统组装的名字 `<market>_<code>_<doc_type>_<日期>_<report_id>.<ext>`。

## 背景 / 现状

先读 `AGENTS.md` → `CLAUDE.md` → `docs/REPORTS-FETCHER.md` §5/§8 → 下面两处代码。

生产实测(0700.HK,report_id `2727be0c6689aabad5a3`)上游响应头为:

```
content-disposition: attachment; filename="unknown__INTERIM______ 2026__2727be0c6689aabad5a3__12450fc853eb941e1680.pdf"; filename*=UTF-8''unknown__INTERIM__%E4%B8%AD%E6%9C%9F%E5%A0%B1%E5%91%8A%202026__2727be0c6689aabad5a3__12450fc853eb941e1680.pdf
content-type: application/pdf
```

现状问题(T-12,docs/P3-TASKS.md):
1. `app/reports/client.py::_filename_from_disposition` 按 `;` 顺序遍历,先遇到 `filename=` 就返回 ASCII 回退名,**从未用到 `filename*`**(它排在后面)。
2. `app/web/routes/reports.py::api_archive_file` 只输出 `filename="<经 _ascii_filename 把非 ASCII 替换成 _>"`,没有 `filename*`,浏览器拿到 `unknown__INTERIM______ 2026__….pdf`。

可用元数据:`api_archive_file` 里没有报告元数据,但 `client.get_report(report_id)` 能拿到
`market/symbol/doc_type/report_period/filing_date/title`(见 REPORTS-FETCHER.md §5、integration-kit/API.md §5),
用它组装回退名。`symbol` 是上游规范化形式(港股 `00700`),本系统代码映射见 `app/reports/symbols.py`。

## 实现提示

- RFC 5987 解析:`value = part.split("=",1)[1]`,形如 `UTF-8''xxx` → `charset, _, enc = value.partition("''")`,`urllib.parse.unquote(enc, encoding=charset or "utf-8", errors="strict")`,`UnicodeDecodeError`/`LookupError` 时回退。
- `Content-Disposition` 里 `filename*` 的值**不要加引号**;`filename=` 的值加引号且内部不能有 `"`。
- 不要把 `title` 直接塞进文件名(上游标题可能含空格、全角标点);组装名以 doc_type + 日期为主。

## 已知坑

- 本机 `HTTP_PROXY` 劫持 127.0.0.1;客户端已忽略系统代理,手工 curl 加 `--noproxy '*'`。
- mock 的 `Content-Disposition` 与生产形态可能不同(见 integration-kit/mock/server.py 的 file 响应),两种都要能处理;不要为迁就 mock 改 integration-kit。
